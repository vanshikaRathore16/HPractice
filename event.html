Arrays: typeof [] is "object", use Array.isArray([]) to check if it’s really an array. // Error Handling?------------------------------------------------------------------------------------ JavaScript provides try, catch, finally, and throw for error handling. How catch knows the type of error When an error occurs in the try block, JavaScript creates an “Error object” automatically. This object contains all the info about the error: name → the type of error (ReferenceError, TypeError, RangeError, etc.) message → description of the error stack → stack trace The catch block receives this error object as a parameter. LocalStorage and SessionStorage-------------------------------------------------------------------------- Common Methods Both LocalStorage and SessionStorage have the same methods: setItem(key, value) → store data getItem(key) → retrieve data removeItem(key) → remove specific key clear() → remove all data
